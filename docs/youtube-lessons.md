## Publishing

These URLs are stored in `data/generated/admin-content.json`. The admin content
import replaces that snapshot, so the admin source must retain these mappings
before the next import. Review this table against any new export before publishing.
Unlisted videos remain accessible to people who have their URLs; they must keep
embedding enabled to play inside the website.
